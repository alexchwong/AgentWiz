Saving runs

MCP servers

Shared by every workspace. Tokens are kept in memory only, or read from the named environment variable.

Workspaces

A workspace holds this project's profiles, blocks, examples, roles, contracts and saved runs. Switching releases the current workspace's lock and opens another. Save or discard Workshop changes first. Session API keys and MCP tokens are memory-only and are not carried across a switch or reset.

Launch in another process

This starts a separate AgentWiz process. Only one process can own a workspace.


  




  
Roles

  
Roles select saved model profiles for blocks and Workshop assistance. Local means this machine (LM Studio or a loopback OpenAI-compatible server, including llama-server). Cloud roles never use local profiles. Neither location falls back to the other.
